## Engineering principles

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>◈ Purpose before features</h3>
      <p>Design around real workflows and problems worth solving.</p>
    </td>
    <td width="50%" valign="top">
      <h3>◇ Clarity over hype</h3>
      <p>Keep implemented functionality, beta work and research visibly distinct.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>◎ Local-first thinking</h3>
      <p>Prioritize meaningful local functionality and user control where appropriate.</p>
    </td>
    <td width="50%" valign="top">
      <h3>⬡ Verifiable foundations</h3>
      <p>Prefer explicit contracts, bounded behavior, tests and clear trust boundaries.</p>
    </td>
  </tr>
</table>
