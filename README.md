## Featured projects

### Nexus Ecosystem — local-first productivity workspace

A connected workspace for notes, tasks, planning, writing and development. Its public software foundation spans desktop and mobile clients, with a shared runtime and open-core approach.

**Stack:** TypeScript · React · Electron · Capacitor  
**Status:** Beta / active development. Cloud and Pro capabilities are planned or privately developed; they are not claimed as generally available here.  
**Explore:** [Product website](https://nexusproject.dev) · [Source repository](https://github.com/YoungJibbit95/Nexus-Ecosystem)

### Nexus Cerebri — deterministic temporal planning

An open-source Rust planning foundation for bounded temporal reasoning, typed evidence and explicit constraints. The planner is deterministic today; machine-learning integration is a future research direction, not a currently shipping feature.

**Stack:** Rust · Algorithms · Temporal Planning  
**Status:** Unreleased / under release qualification.  
**Explore:** [Source repository and documentation](https://github.com/YoungJibbit95/Nexus-Cerebri)

## What guides Nexus

- **Useful by design.** Build software around real workflows, not feature lists.
- **Transparency over hype.** Distinguish implemented features, prototypes and research.
- **Local-first where appropriate.** Keep users in control of their work.
- **Verifiable foundations.** Prefer clear contracts, testable behavior and explicit boundaries.

## More to come

The Nexus family is growing. Supporting tooling and potential cloud capabilities remain under active development; public announcements will follow actual release readiness.
